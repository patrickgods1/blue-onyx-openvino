Benchmark

Runs each model on each device over the chosen datasets with the production pipeline (decode, preprocess, inference, postprocess), grades accuracy (AP@0.5, or the frame-level ROC AUC: how well a frame's top confidence separates frames with an object from frames without, which is Blue Iris's alert decision; against ground truth, or against a reference model where a dataset has none) and speed (full request p50), and checks that every device detects the same objects as the CPU. The recommended device of a model is its best-graded device whose detections agree with the CPU; within 5% of the best speed the configured device is kept. The same predictions are also scored at every confidence threshold (no extra inference) to find each model's best confidence threshold for the chosen objective. Results: {{ results_file }} (the benchmark CLI writes the same file). JSON: /v1/benchmark.
